Demographics / sleep-architecture figures for the paper live in `results/demographics_V1/`, generated by three scripts in `code/` (run from repo root, venv active):

- **sleep_stage_pies.py** — per-group sleep-stage pies (Wake/N1/N2/N3/REM) + 3-group stats table beneath. Has `orientation` arg: `"horizontal"` (1×3 row, `sleep_stage_pies.png`) and `"vertical"` (3×1 stack YA/HE/MCI + table, `sleep_stage_pies_vertical.png`). `STAGE_COLORS` dict is the canonical stage palette (Wake grey, N1 yellow, N2 green, N3 purple, REM red).
- **n2_bouts_table.py** — per-group N2-bout metrics (count, mean length, total dur, rel. location, % of N2) + 3-group stats → `n2_bouts_table.png/.csv`. Bout def matches `new_iso/mult_chan` (NREM2 split around BAD, merge, ≥300 s). Walks each subject's `cleaned_annotations.txt` (falls back to `annotations.txt`) via `code/utils/subject_summary.parse_annotations`.
- **combined_demographics_table.py** (created 2026-06-03) — merges the above two into ONE 8-col table (`Variable | Young | Elderly | MCI | Omnibus p | Y-vs-E | Y-vs-MCI | E-vs-MCI`) with two section bands ("Sleep architecture" / "N2 bout properties"). Reuses the other two modules' stats fns (imports them). Stage cells colored with `STAGE_COLORS`. Auto-sizes columns (`auto_set_column_width`); band labels rendered as overflow text; title/footer anchored to the measured table bbox; footer wrapped to table width. → `combined_sleep_n2_table.png/.csv`.

All three read the **"subjects" tab** of the subjects Google Sheet (ID `1bGjm-GKiwBQT3QwvHM5JGbjI4kRLmkH5i_RfJ0I3SWw`, SA key `C:/Users/Shaked/.gcp/refined-spirit-494512-e8-059d94c0eb34.json`) — so figures reflect sheet state, NOT local pipeline runs. Group n as of 2026-06-03: YA=34, HE=38, MCI=31. Stats pipeline (shared): Shapiro → ANOVA/Kruskal-Wallis → Tukey HSD / Dunn(Holm). Follows [[feedback_versioned_output_dirs]] (demographics_V1). See [[reference_subjects_sheet]].
