**Key findings (N=36 / V9 — SUPERSEDED, see above):**
- Peak frequency **faster** with age: Young < Elderly = MCI, ANOVA p=0.0020 (post-hoc Y-vs-E p=0.011, Y-vs-MCI p=0.004).
- Bandwidth same direction, now **borderline significant** (ANOVA p=0.038), carried by Young-vs-Elderly only (post-hoc Y-vs-E p=0.045; Y-vs-MCI ns). Treat as a borderline/test-dependent trend, not a robust effect (was ns at N=35). Report cautiously.
- Whole-scalp AUC unchanged (Kruskal-Wallis p=0.348), but **focally reduced**: one significant central-parietal cluster p=0.016, 10 electrodes (Y>E and Y>MCI; the young-adult hotspot flattens with age).
- ROI normalized-AUC omnibus ns (ANOVA p=0.182; means Y 1.099 > E 1.042 > MCI 1.021) — full-ROI averaging dilutes the focal cluster effect.
- **Elderly = MCI on every measure.** No ISFS scalar correlates with MoCA (pooled E+MCI **n=43** after 11 elderly MoCA added 2026-06-15, all |r|≤0.12, p≥0.45; was n=32/|r|≤0.13). S2 in `moca_correlation_V2` (sigma_fix source); elderly MoCA now 27.2±2.6 n=29.

**BANDWIDTH IS DURATION-DEPENDENT (new 2026-08-13, [[project_c429_c390_results]]).** The C429 ANCOVA
found total analyzed N2 duration is the *strongest* predictor of whole-scalp bandwidth in the model
(r = +0.386, partial η² = 0.128, p = 0.0002 — larger than the group effect), and the group term falls
p = 0.061 → 0.206 once it is included. Peak frequency is untouched (p 0.0026 → 0.0034, covariate
p = 0.94), so the headline is safe. But the already-cautious bandwidth caveat above now has a
mechanism: longer analysed recordings give wider fitted peaks, i.e. a property of the estimator.
**Never present bandwidth as an aging effect**; the duration dependence belongs in Methods or
Limitations. Also new: WASO / REM latency / sleep efficiency all show the same Young-vs-both,
Elderly = MCI pattern, independently corroborating the aging-not-MCI framing.
